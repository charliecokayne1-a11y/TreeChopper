SHARD FARM (Fabric client mod, Minecraft 1.21.11)

The zip is SOURCE CODE. Modrinth only accepts the built .jar.

NO-INSTALL BUILD (GitHub does it for you)
1. Make a free account at github.com and create a new repository.
2. Upload everything from this folder (including the .github folder).
3. Open the repo's Actions tab, wait for the "build" run to finish (about 3-5 minutes).
4. Open the finished run, download the "shardfarm-jar" artifact, unzip it -> shardfarm-1.0.0.jar

INSTALL
- Modrinth App -> instance with Fabric + Minecraft 1.21.11 -> install Fabric API
- Content -> Add content -> Add from file -> pick shardfarm-1.0.0.jar

USE
- Hotbar: saplings, bone meal, your axe.
- Aim at the block you want to plant on.
- RIGHT SHIFT = menu, J = start/stop.

LOCAL BUILD (alternative): Java 21 + "gradle build", or copy gradlew/gradle folder from fabricmc.net/develop/template.
